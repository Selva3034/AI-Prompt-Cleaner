FAQ

Frequently asked questions.

Everything you need to know about Promptly AI.

What does Promptly AI do? +

Promptly AI takes a rough or unclear idea and transforms it into a clearer, structured and more effective AI prompt.

Which AI model does it use? +

The application sends the prompt to the Groq API using an OpenAI-compatible API interface.

Is my API key exposed? +

No. The API key is stored on the server and is not included in the frontend JavaScript.

Is there a prompt length limit? +

Yes. Promptly AI accepts prompts up to 2,000 characters.

Does the website use tracking cookies? +

The application does not introduce tracking cookies. Browser local storage is used for preferences such as theme selection and cookie-banner dismissal.
